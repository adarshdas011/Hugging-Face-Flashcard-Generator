# AI Flashcard Generator

A simple Python project that generates 5 AI-powered flashcards on any topic using the Hugging Face Inference API.

## Features

- Generate 5 flashcards on any topic
- Simple question and answer format
- Short and easy-to-understand answers
- Uses Hugging Face AI
- API token is stored securely using `.env`

## Technologies Used

- Python
- Hugging Face Inference API
- GLM-5.3
- python-dotenv
